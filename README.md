# ProjetoJava8
Cafeteria em Java 8 (EJB) para demonstrar controle de estado e memória. Um Singleton gerencia o cardápio, um serviço Stateful isola o carrinho por usuário e um Stateless calcula o pedido de forma concorrente. Parte da minha experiência com legado que evoluirá para mostrar tudo o que aprendi em 10 anos de carreira.
